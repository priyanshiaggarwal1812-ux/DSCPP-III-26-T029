How to read this: latency cards time the matching step only, inside the engine. The round-trip chart includes HTTP and the network, so the whole system is not "low-latency end to end". Report p99 as well as the average, because one slow order can hide behind a good average. Build the engine with -O2 and warm it up with a few thousand orders before measuring. RAM is lost on a crash, so the database worker saves trades and open orders are reloaded on restart.
